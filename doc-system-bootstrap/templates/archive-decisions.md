# Superseded Decisions

Decisions that are no longer in force, with their original reasoning intact.
Moved here from their area doc when replaced.

**This file is history, never the current state.** To know how the project works
today, read the area docs — nothing here is in force. Its purpose is to answer
"why was it done the other way before, and what changed".

Ordered by ID, newest first. Never edit the text of an archived decision: it
already carries its `Superseded by` line and that is the only edit it ever received.

```markdown
> **Decision:** (2026-08-01, D7) [original text, whole, with its trade-off]
>
> **Superseded by D14 (2026-09-02)** — `infrastructure.md` § Docker.
```
