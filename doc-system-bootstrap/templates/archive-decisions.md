# Archived Decision Detail

This file mirrors `decisions.md` — a **list of `### D-n` sections, no table**. One
meaning only: every decision here is **superseded** — no longer true. Its `### D-n`
was moved here whole (heading included), marked `**Superseded by D-m**`. **This is not
the current state** — to know how the project works today, read `decisions.md`; nothing
here is in force.

Ordered by ID, newest first. Never edit the text of an archived decision — a superseded
one carries its `Superseded by` line, and that is the only edit it ever receives. Each
`### D-n` is copied whole — heading and all — so `grep '^### D'` and `### D-n` → next
`###` work here too. IDs are never reused, so an archived `D-n` never collides with a
live one.

```markdown
### D7 — Containers are production-only
<original block, whole, with its trade-off>

**Superseded by D14 (2026-09-02)**
```
